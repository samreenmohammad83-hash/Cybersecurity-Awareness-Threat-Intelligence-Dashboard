# Core Concepts

## Cybersecurity Awareness
Helps people recognize and avoid security risks such as phishing, password reuse, social engineering, unsafe browsing, and suspicious attachments.

## Cyber Threat Intelligence
Collects and analyzes information about threats to support defensive decisions.

## IOC
An Indicator of Compromise is an artifact such as an IP, domain, URL, hash, or sender domain that can support an investigation.

## IOA
An Indicator of Attack describes behavior or activity patterns that can suggest an attack. It is more behavior-oriented than a static IOC.

## Vulnerability / CVE / CVSS
A vulnerability is a weakness that could be abused. A CVE identifier names a publicly cataloged vulnerability record. CVSS provides a standardized severity scoring framework. This project uses synthetic vulnerability records.

## Threat Feed
A source of threat-related observations or intelligence. Sources can have different reliability.

## Threat Actor
A conceptual term for a person or group conducting or attempting malicious activity. This project does not attribute synthetic records to real actors.

## TTP
Tactics, Techniques, and Procedures describe adversary goals, methods, and implementation details.

## MITRE ATT&CK
A knowledge base that organizes adversary behaviors into tactics and techniques.

## Threat Enrichment
Adding context to raw observations.

## Threat Correlation
Linking observations based on shared evidence or context.

## Threat Hunting
A proactive defensive process for looking for signs of suspicious behavior in authorized environments.

## SOC
A Security Operations Center monitors, triages, investigates, and coordinates response to security events.
